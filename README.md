# Terapia Ágatha — Lilian Cristina

Site estático criado em HTML, CSS e JavaScript.

## Como abrir
1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador.
4. Para desenvolvimento, pode usar a extensão **Live Server** do VS Code.

## Estrutura
- `index.html` — conteúdo e estrutura da página
- `style.css` — visual, responsividade e animações
- `script.js` — menu mobile, animações e formulário
- `assets/` — imagens enviadas nesta conversa

## Observações
- Os botões de atendimento apontam para o WhatsApp fornecido.
- Os depoimentos estão como placeholders para evitar inventar relatos. Substitua pelos depoimentos reais e autorizados.
- O formulário abre o WhatsApp; para envio real de dados por e-mail/banco, será necessário conectar um serviço/backend.
- O visual usa as imagens enviadas como referências e uma paleta rosa, vinho, creme e dourado.
